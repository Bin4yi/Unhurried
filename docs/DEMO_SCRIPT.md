# Demo voice-over script

Simple English, short sentences. About 3 minutes in total.
Numbers come from `bench/results/20261105_000043_real_self.json`. Never say a number that is not in a results file.

**How to read this script:** look at the line, then say it **in your own words**, at your own pace. You do not need to read it exactly. Pauses and repeats are fine: Voice Studio will show them, and that is part of the demo.

---

## Shot 1 · Title (0:00–0:12)

**Say:**
> Hi, I'm Binula. I have a stammer.
> When I talk to voice AI, it cuts me off in the middle of my sentence.
> So I measured it, and I built Unhurried.

**Caption:** *I have a stammer. Voice AI cuts me off. I measured it.*

---

## Shot 2 · Side by side, live (0:12–0:45)

**Say:**
> This is the same microphone and the same sentence.
> On the left is a normal voice bot. On the right is Unhurried.
> Watch what happens when I pause.
> The normal bot replies while I am still talking.
> Unhurried shows "take your time", and waits.
> When I finish, it sends my whole sentence.

**Caption:** *Same mic, same sentence. Left: normal end-of-speech. Right: Unhurried.*

---

## Shot 3 · Why it waited (0:45–1:05)

**Say:**
> Every pause is a decision: wait, or send.
> First, code checks my words. My sentence ended on "for", so more is coming.
> Then my own audio code checks my voice: pitch, fade, and if I am still voicing.
> Muse Spark is only asked when the code is not sure, and it gets 700 milliseconds.

**Caption:** *Words first, then voice, then Muse Spark only if unsure.*

---

## Shot 4 · Clean sentence and confirm (1:05–1:30)

**Say:**
> The bot gets a clean sentence. Repeats are removed, and I can always see what I said.
> If I correct myself, like "two, no, three people", it keeps what I meant.
> It only removes words. It never adds them. A code guard checks every name, number and time.
> Before it books anything, it asks me first.

**Caption:** *Only removes, never adds. A code guard checks every name, number and time.*

---

## Shot 5 · Voice Studio and before/after (1:30–2:10)

**Say:**
> This voice-over is my real voice, recorded with my stammer.
> Voice Studio cleaned it.
> Muse Spark 1.2 listens for stammers. Meta's wav2vec 2.0 finds exactly where each one is in the audio.
> Code checks the evidence, and I approve every cut.
> Here is voice editing off… and on. Every sound is still my own voice.

**Caption:** *Muse Spark 1.2 listens. wav2vec 2.0 places each cut. I approve every cut.*

*(Play 5 seconds with Voice editing OFF, then the same 5 seconds ON.)*

## Shot 6 · Results (2:10–2:35)

**Say:**
> I measured it on my own voice.
> In fifteen recordings, while I was still talking, a normal voice bot replied **fourteen** times.
> With Unhurried, it replied **two** times.
> And zero invented words.

**Caption:** *Measured on my own voice: 14 → 2 replies while I was still talking. Zero invented words.*
